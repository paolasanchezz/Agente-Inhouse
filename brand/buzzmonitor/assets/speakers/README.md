# Fotos dos speakers (Pocket Events)

Uma imagem por pessoa, nomeada com o `id` usado em
`landing-pages/build/templates/pocket-event/speakers.json`.

- Formato: JPG quadrado, no minimo 336x336 (a LP exibe em 168px, 2x pra tela retina)
- Enquadramento: rosto centralizado, com folga em volta (a foto e recortada em circulo)
- Sem foto cadastrada, a LP mostra as iniciais com o degrade da marca. Nunca fica
  um placeholder vazio no ar.
