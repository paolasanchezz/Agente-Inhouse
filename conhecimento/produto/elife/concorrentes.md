# Mapa Competitivo — Elife

## Regras para Mencao de Concorrentes em Newsletters
- **Nunca** falar negativamente de concorrentes de forma direta
- **Nunca** citar concorrentes pelo nome nas newsletters
- Posicionar Elife pelos proprios meritos e resultados
- Quando necessario contrastar, usar termos genericos: "agencias generalistas", "ferramentas de monitoramento puras", "plataformas de pesquisa tradicional", "solucoes sem consultoria especializada"

## Movimentos Recentes do Mercado (2026)

- **Consolidacao em mega-agencias**: Fusao Wunderman Thompson + VMLY&R formou a VML — mercado caminha para gigantes generalistas; espaco aberto para especialistas profundos como a Elife
- **Performance domina o discurso**: NP Digital lidera em performance mensuravel; reforça o argumento da Elife de que dados de comportamento do consumidor (social intelligence) sao complementares aos dados de performance
- **Limite das ferramentas de monitoramento**: Stilingue e concorrentes de software crescem, mas nenhum resolve o problema de plataformas sem API (ex: TikTok) — a metodologia de coolhunting da Elife e diferencial nao replicavel por software puro
- **Social CRM como gerador de receita**: Case Swift (+755%) posiciona o atendimento digital nao como custo operacional, mas como canal de crescimento
