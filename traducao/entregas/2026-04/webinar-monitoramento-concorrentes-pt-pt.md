## Principais substituições aplicadas

1. **"está fazendo" → "está a fazer"** (perífrase obrigatória PT-PT)
2. **"seu / sua" → "o seu / a sua"** (possessivo com artigo definido — ex: "a sua empresa", "os seus resultados")
3. **Expressões idiomáticas traduzidas:**
   - "Na real" → "Na verdade"
   - "Olhadinha" → "Olhadela" (diminutivo nativo PT-PT)
   - "No chinelo" → "a comer pó" (expressão PT-PT equivalente para "deixado para trás")
   - "Sem enrolação" → "sem rodeios"
   - "Sair na frente" → "sair à frente"
4. **Vocabulário técnico:**
   - "Monitorar / Monitoramento" → "Monitorizar / Monitorização"
   - "Ao vivo" → "Em direto"
   - "Demanda" → "Procura"
   - "Time" → "Equipa"
   - "Metas agressivas" → "Metas ambiciosas" (evita conotação hostil no PT-PT)
   - "Entender" → "Perceber"
   - "Aprimorar" → "Melhorar"
   - "Gerencia" → "Gere"
5. **CTA com ênclise:** "Quero me inscrever" → "Quero inscrever-me" (natural PT-PT, conforme Sage PT)
6. **Fuso horário adaptado:** 11h (Brasília) → 15h (Lisboa) — conversão para audiência portuguesa (UTC+1 vs UTC-3 = +4h em Maio)
