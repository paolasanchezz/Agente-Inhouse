— 01 / Loaders

Indicadores de carregamento

Spinners, dots e barras para sinalizar processamento. Todos rodam com keyframes simples e funcionam em qualquer tamanho.

Spinner clássico

L01

Borda parcial girando — o tradicional.

Ver código CSS 
.spinner {
  width: 50px;
  height: 50px;
  border: 4px solid rgba(255,255,255,0.1);
  border-top-color: #EF863C;
  border-radius: 50%;
  animation: spin 0.9s linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}

— 09 / Formulários

Inputs com identidade

Campos que toda LP nossa precisa. Estilizados para não brigar com o brand e sem perder a acessibilidade nativa.

Float label

FM01

Label que sobe quando o campo é focado ou preenchido.

Ver código CSS 
/* HTML: <div class="field"><input placeholder=" "><label>Email</label></div> */
/* O placeholder=" " (espaço) é OBRIGATÓRIO — habilita :placeholder-shown */
.field { position: relative; }
.field input {
  width: 100%;
  padding: 18px 16px 8px;
  background: #232c46;
  border: 1px solid #3a4870;
  border-radius: 9px;
  color: #f0f4ff;
  outline: none;
}
.field input:focus { border-color: #EF863C; }
.field label {
  position: absolute;
  left: 16px; top: 14px;
  color: #8593b3;
  pointer-events: none;
  transition: all 0.2s ease;
}
.field input:focus + label,
.field input:not(:placeholder-shown) + label {
  top: 4px;
  font-size: 11px;
  color: #EF863C;
}

Scroll reveal

A04

Em produção, dispare a animação com IntersectionObserver ao entrar na viewport.

Ver código CSS + JS 
/* CSS: estado inicial + classe ativa */
.reveal {
  opacity: 0;
  transform: translateY(20px);
  transition: all 0.7s cubic-bezier(0.4, 0, 0.2, 1);
}
.reveal.in-view {
  opacity: 1;
  transform: translateY(0);
}
/* Importante (GUIDELINES §4): manter fallback */
@media (prefers-reduced-motion: reduce) {
  .reveal { opacity: 1; transform: none; }
}

/* JS: */
const io = new IntersectionObserver(entries => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add('in-view');
      io.unobserve(e.target); // uma vez só
    }
  });
}, { threshold: 0.15 });
document.querySelectorAll('.reveal').forEach(el => io.observe(el));
