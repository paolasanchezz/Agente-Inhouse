Dúvidas frequentes

Por que empresas são banidas do WhatsApp?

Os casos mais comuns envolvem violação dos termos de uso da Meta: várias pessoas atendendo pelo aplicativo num celular compartilhado, ferramentas não-oficiais de multiatendimento e disparos em massa fora das regras.

A Cxpress usa a API oficial do WhatsApp?

Sim. A integração é feita pela API oficial, o caminho que a Meta autoriza para o atendimento de empresas.

Vou precisar trocar de número para usar a API oficial?

Não. Com o WhatsApp CoEx, o mesmo número pode operar no aplicativo e na API oficial ao mesmo tempo.

Posso conectar mais de um número à Cxpress?

Sim, é possível conectar mais de um número na mesma operação.

Quais canais podem ser integrados?

Podem ser integrados de forma nativa o WhatsApp, e-mail, redes sociais (Facebook, Instagram), telefone e chat do site.
