Forma orgânica · degradê fluido

Refeito com SVG path morfando entre 3 estados (curvas Bézier cúbicas) + mesh gradient via radial-gradients sobrepostos com centros animados (sem conic, sem "costura"). Cores brand Buzzmonitor. CSS + SMIL puro. Respeita prefers-reduced-motion.

1 · O objeto isolado

showcase — pra apreciar a forma e o movimento

Como funciona — um único path SVG (curvas Bézier cúbicas) morfa entre 3 estados em 22s. Dentro dele, três radial-gradients (peach, rosa, laranja) deslizam com centros animados em durações dessincronizadas (16s/18s/24s). Sem conic — o resultado é uma mistura suave e contínua, tipo "luz líquida". Glow ao redor via drop-shadow.
