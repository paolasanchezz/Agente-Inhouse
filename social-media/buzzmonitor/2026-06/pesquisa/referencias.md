# Perfis de Referência B2B SaaS — Junho 2026

## HubSpot
- LinkedIn: carrosseis educativos com dados de pesquisa própria, infográficos de tendências, textos longos com perspectiva de liderança
- Instagram: visual mais descontraído, bastidores de cultura, dados em formato acessível
- Cadência: 5x/semana LinkedIn, 3x/semana Instagram
- Hook que funciona: dado específico na primeira lâmina ("73% dos profissionais de marketing...")
- Junho 2026: Copa como gancho para análise de dados de comportamento do consumidor

## Sprout Social
- LinkedIn: dados do Sprout Social Index publicados como posts de alto engajamento, relatórios transformados em carrosseis
- Cadência: 3-4x/semana
- Temas de junho: comportamento nas redes durante grandes eventos, IA em social media
- Diferencial: usa dados próprios como âncora — o mesmo modelo que Buzzmonitor deve usar

## Buffer
- LinkedIn: transparência radical (dados internos da empresa, erros e aprendizados), conteúdo educativo sobre social media
- Instagram: bastidores de trabalho remoto, cultura da empresa, resultado de experimentos próprios
- Cadência: 3x/semana
- Hook que funciona: "nós testamos X e aqui está o que descobrimos"
- Referência de formato: thread → carrossel com insights de dados próprios

## RD Station
- LinkedIn: conteúdo educativo sobre marketing digital, cases brasileiros, dados do mercado nacional
- Instagram: mais informal, dados rápidos, linguagem brasileira
- Cadência: 4x/semana LinkedIn, 3x/semana Instagram
- Mais próximo do público da Buzzmonitor no contexto BR
- Copa 2026: provável série sobre campanhas das marcas + análise de dados

## Aprendizados aplicáveis à Buzzmonitor em Junho
1. **Dado proprietário é o maior diferencial**: posts com dados do estudo de diversidade têm vantagem que nenhum concorrente pode replicar
2. **Hook na primeira lâmina**: o número surpreendente precisa estar no primeiro slide/primeira frase
3. **Copa como laboratório**: usar Copa como "evento ao vivo" para demonstrar capacidade de social listening em tempo real
4. **Adaptação por rede obrigatória**: mesmo dado, formatos completamente diferentes por plataforma
5. **Consistência temática por semana**: definir um "tema da semana" mantém coerência entre as 3 redes
